A simple Python program that allows users to enter their expenses and calculates the **total amount spent**.

📌 Features

- Enter multiple expense amounts
- Add all expenses together
- Type `quit` to stop entering expenses
- Displays the total amount spent

 🛠️ Technologies Used

- Python
- `input()`
- `while` loop
- `if` condition
- `int()`
- Accumulator (`total = total + expense`)
