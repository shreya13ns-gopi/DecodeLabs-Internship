# DecodeLabs-Internship
This is a Python To-Do List program that allows users to add tasks, view the saved tasks, and exit the program through a simple code.
How it works
tasks = [] : Creates an  list to store tasks.
1. Add Task : Takes a task from the user and adds it using append().
2. View Tasks : Displays all stored tasks using a for loop and enumerate().
3. Exit : Ends the program 
Invalid choice : Shows an error message and asks the user to try again.
while True : Keeps the program running until the user chooses Exit.
Key Python concepts used:

Lists, append(), loops, if-elif-else, input(), enumerate(), and break.
